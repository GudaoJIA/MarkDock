# 04 · 使用指南

[English](../EN/04-user-guide.md) | **简体中文**

日常操作从文档树和编辑器开始。首次添加工作区见[快速上手](02-getting-started.md)，资源与偏好见[配置说明](03-configuration.md)。

## 工作区与文档

点击左上角名称进入工作区管理，点击已固定项切换。切换前先保存；冲突、输入法组字或上传未完成时可能暂时无法切换。

“取消固定”不删除文件。取消固定当前工作区会先保存草稿，然后清空可见文档区；失败时保留当前工作区。其他浏览器取消固定不会强行关闭本页正在编辑的文档。

文档树支持新建文档、文件夹，文档与文件夹重命名，以及同一工作区内移动文档。不支持文件夹删除、文件夹拖动或跨工作区移动。

## 编辑模式

| 模式 | 适合做什么 |
| --- | --- |
| 可视化 | 用工具栏、块菜单和 Markdown 输入编辑正文，插入图片和表格 |
| 源码 | 编辑完整 Markdown，包括元数据、模板文本和空行 |

工具栏最右侧的代码图标进入源码，编辑图标返回可视化。两种模式共用草稿、自动保存和撤销历史，分别记住光标与滚动位置；模式切换本身不保存或生成撤销记录。

源码提供行号、高亮、自动换行和查找，粘贴按纯文本处理。不提供独立阅读模式，不执行 HTML、MDX 或模板代码。

## 文字格式与块菜单

工具栏按以下顺序提供入口：

| 分组 | 操作 |
| --- | --- |
| 历史 | 撤销、重做 |
| 行内格式 | 粗体、斜体、删除线、行内代码、超链接 |
| 列表 | 无序列表、有序列表、待办列表 |
| 内容块 | 引用、代码块、分隔线、表格 |
| 资源与查找 | 图片、附件、查找与替换 |

窄窗口可以横向滚动工具区；大纲与模式按钮保留在右侧。行内格式需要选中文字，只有光标时不会预设后续输入样式。

悬停块或聚焦左侧控件，会出现六点柄；标题还会显示 H1–H6。单击六点柄可转换正文、标题、列表和引用，菜单处理的是点击的块，而不是别处的选区。

- 列表转换只处理当前项，下级内容保留并调整层级。
- 引用转换处理整个引用，保留段落边界。
- 表格、代码、图片、分隔线和原文块不提供格式转换。
- 菜单底部“删除该块”可删除整个表格、图片等内容，支持撤销；删除标题保留章节正文。

列表内按 Tab 增加层级，Shift + Tab 减少层级；最外层退级变为正文。只有选中项均为列表时才支持批量调整。

## Markdown 输入

可视化中可使用行首 Markdown 标记，如标题 `#`、列表 `-`、引用 `>`。普通空段落输入 `---` 后按空格，可转换为分隔线。

输入 `/` 打开命令菜单，通过名称筛选内容块；代码、表格、原文块和组字期间不触发。源码模式始终保留原文输入。

不能安全转换的语法显示为可编辑原文块；无法可靠划分时整篇回退为原文。打开或切换不会改写文件，未编辑片段保持原样，修改的结构会按 Markdown 重新生成。

## 链接与表格

选中文字后点击链接按钮，或在已有链接中编辑地址。支持尚未上线的 HTTP(S) 地址、相对路径、锚点和邮箱；裸域名自动补 `https://`，危险协议被拒绝。

普通链接单击显示编辑操作；Command + 点击（Mac）或 Ctrl + 点击（Windows/Linux）在新标签打开。“移除链接”保留文字及其他格式。附件链接单击下载。

表格按钮提供网格与自定义尺寸。第一行作为表头，不支持合并单元格；单元格只支持单段文字与行内格式。Enter 或 Shift + Enter 在单元格间移动，粘贴中的多行和制表符会转为空格。

## 查找与替换

侧栏“查找文档”搜索文件名和正文，包含当前未保存会话的内容。可视化中的 Command/Ctrl + F 打开统一搜索；源码中的同组合使用源码编辑器查找。

工具栏“查找与替换”或 Command/Ctrl + Shift + H 打开文内替换。

- 可视化支持不区分英文大小写的字面匹配，不支持正则、跨段落或跨文件替换。
- 可视化“全部替换”先显示数量并确认，一次操作可撤销。
- 源码查找另有大小写、全词及正则选项；全部替换直接执行，可撤销。

## 图片与附件

| 类型 | 添加方式 | 限制 |
| --- | --- | --- |
| 图片 | 工具栏、拖入、粘贴 | PNG、JPEG、GIF、WebP、AVIF；单张 20 MiB |
| 附件 | 工具栏附件按钮或 `/` 菜单 | 单个 100 MiB |

本地图片和 HTML 内嵌 base64 图片会作为文件上传，再向 Markdown 写入资源地址。普通文本中的 base64 不自动转换。资源位置由[工作区设置](03-configuration.md#工作区资源设置)决定。

上传失败不插入无效链接，允许重试。取消上传可能留下已经保存的资源；删除图片块或撤销插入只删除正文引用，不清理资源文件。

点击正文图片可打开查看器，支持适应窗口、原始尺寸、缩放和平移；查看比例不修改 Markdown。

## 浏览资源

1. 在“设置 → 界面偏好”开启“显示资源目录”。
2. 展开文档树中的资源文件夹。
3. 点击图片预览，或点击其他文件查看信息。

列表按文件夹在前、文件在后排序，每页最多 100 项，可“加载更多”。折叠后重新展开刷新；分页失效时按提示刷新列表。

文件信息提供下载和复制路径，复制的是**工作区相对路径**，不是当前文档的 Markdown 引用。图片加载失败时可重试或下载。

资源文件不会进入正文编辑会话，不影响自动保存或撤销历史。不提供资源删除、重命名、移动、新建或拖入正文；不内嵌预览 PDF、Office、HTML、SVG、脚本和 Markdown 附件。

## 大纲与写作工具

可视化右侧大纲用于跳转标题；标题旁箭头折叠章节。折叠只改变显示，搜索、统计和保存仍包含全文；源码模式不提供大纲。

六点柄也可拖动正文块。列表项带上下级列表，标题带上章节；原文块不可拖动。按 Esc 取消，移动可撤销。此操作与侧栏的磁盘文件移动不同。

底部显示字数、阅读时间和写作目标，可在设置中分别隐藏。目标保存在浏览器，不写入 Markdown。字数按中文逐字、英文和数字逐词估算，阅读时间按每分钟 400 个单位估算。

## 移动与重命名

从文档菜单选择“移动到…”，或将文档拖到同一工作区的普通目录。目标已存在时拒绝，不覆盖或合并。

应用会按资源归属处理专属目录，并更新受支持的本地 Markdown 链接。固定资源不会随文档搬迁。缺失资源、不支持的引用或外部修改可能阻止操作。

**外部文件管理器的移动不由 MarkDock 跟踪。** 涉及重要目录时先备份；避免应用与外部工具同时写入。文件移动不属于正文撤销历史。

## 删除文件与垃圾箱

在文档菜单点击“移到垃圾箱”，可从成功提示或侧栏“垃圾箱”恢复。仅支持 Markdown 文件，不支持删除工作区或文件夹。

专属资源随文档进入垃圾箱，共享资源保留。恢复使用原路径；同名文档或资源目录占用时停止，不覆盖。文件删除不纳入正文撤销历史。

彻底删除和清空需要确认，不自动过期清理；它们不会删除独立历史备份。详细边界见[备份与恢复](05-backup-and-recovery.md)。

## 保存、退出与限制

编辑自动保存，也可手动保存。遇到外部修改会暂停并提示冲突；保留当前页面，选择重新读取或另存副本，见[冲突处理](05-backup-and-recovery.md#保存失败与冲突)。

侧栏“退出登录”会先保存驻留文档；失败、组字或上传中可能无法退出。登录失效时使用“重新登录”，不要刷新未保存的页面。

只支持 UTF-8 Markdown，单文件最多 5 MiB。隐藏项、node_modules、符号链接及内部数据目录不进入普通文档树。扫描上限与编辑历史预算相互独立，范围超限见[故障排查](06-troubleshooting.md#打开工作区缓慢或范围超限)。
