# 02 · 快速上手

[English](../EN/02-getting-started.md) | **简体中文**

本页从已启动的 MarkDock 开始。尚未安装时，先阅读[部署说明](01-deployment.md)。

## 1. 登录

打开服务地址，输入部署时设置的密码。MarkDock 没有默认密码或注册入口；忘记密码时由服务维护者[重置密码](05-backup-and-recovery.md#重置密码)。

## 2. 固定一个文件夹

1. 点击左上角“工作区管理”。
2. 在“数据位置”中浏览文件夹；也可通过底部路径编辑按钮输入路径。
3. 选中目标后点击“固定到工作区”，或将窗口内的文件夹拖到左侧已有工作区。
4. 点击左侧已固定的工作区，打开文档列表。

**选中的文件夹就是工作区。** 固定仅建立入口，不移动、复制或创建文件夹。外部 Finder 拖入不作为服务器目录引用。

浏览的是服务所在设备的目录。Docker 用户看到的是挂载后的容器路径，例如 `/workspaces`，不是电脑上的原始路径。没有数据位置时，查看[目录访问范围](03-configuration.md#服务配置)。

## 3. 开始编辑

在文档树打开 `.md` 文件，或使用新建文档按钮。工具栏最右侧按钮在可视化与源码之间切换，输入后自动保存，也可按 Command/Ctrl + S。

不支持可视化排版的语法会显示为可编辑原文，不会执行 HTML 或模板代码。详细操作见[使用指南](04-user-guide.md)。

## 4. 按需调整设置

- 工作区名称旁的设置按钮：配置此工作区的图片与附件目录。
- 侧栏底部“设置”：调整当前浏览器的语言、外观、历史预算和快捷键。
- 想在文档树查看资源：开启“设置 → 界面偏好 → 显示资源目录”。

三类设置的保存位置见[配置说明](03-configuration.md)。

## 打开过程与退出

大目录打开时会显示当前阶段、实际检查数量与耗时。只读扫描阶段可点击“取消打开”；保存和实际恢复阶段需要等待完成。不要把进度暂时不变化理解为操作已失败。

退出前确认保存完成。保存失败或冲突时保留当前页面，按提示处理，避免刷新造成未保存输入丢失。
