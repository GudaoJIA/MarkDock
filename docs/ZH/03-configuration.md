# 03 · 配置说明

[English](../EN/03-configuration.md) | **简体中文**

Markdock 的设置分为三层，保存位置和作用范围不同。

| 设置 | 入口 | 保存位置 | 作用范围 |
| --- | --- | --- | --- |
| 服务配置 | 启动环境变量 | 部署环境或环境文件 | 同一服务的所有访问者 |
| 工作区资源 | 工作区旁的设置按钮 | 工作区根 `.markdock.json` | 当前工作区 |
| 界面、历史、快捷键 | 侧栏“设置” | 当前浏览器 | 同源标签页；不跨设备 |

## 服务配置

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `MARKDOCK_DATA_DIR` | `~/.config/markdock/` | 固定列表与密码哈希文件；远程模式必须指定绝对路径 |
| `MARKDOCK_WORKSPACE_ROOTS` | 未设置 | 服务可访问的绝对目录，使用 JSON 数组；远程模式必须非空 |
| `MARKDOCK_PUBLIC_ORIGIN` | 未设置 | 唯一外部 HTTPS 地址，不能包含路径、查询或末尾斜线 |
| `MARKDOCK_HOST` | `127.0.0.1` | 生产监听地址；非回环监听要求完整远程配置 |
| `PORT` | `3000` | 服务端口 |

允许根示例：

```sh
MARKDOCK_WORKSPACE_ROOTS='["/srv/blog","/srv/notes"]'
```

未设置允许根时，本机模式可手动输入路径，不自动展示主目录；明确设为 `[]` 会禁止所有工作区路径。配置后，浏览、固定、打开和文件访问均受允许根限制，仍需满足操作系统权限；不支持符号链接导航。

Docker 中填写容器内路径。宿主机路径由 Compose 的挂载配置指定，应用不会自动发现挂载。修改环境配置后重新启动服务；部署示例见[部署说明](01-deployment.md)。

## 工作区资源设置

点击左上角工作区名称进入“工作区管理”；名称右侧的齿轮直接打开当前工作区设置。管理窗口中也可设置其他工作区，非当前工作区会先按保存保护流程打开。选中的文件夹就是工作区根，文档树、搜索、新建和移动均在这个范围内。设置不能扩大工作区或服务部署的访问权限。

设置通过三张目录示意卡片选择资源规则，宽窗口并排、窄窗口上下排列。可用 Tab 聚焦、方向键选择、空格确认；修改图片或附件路径会即时更新当前示例，切换卡片会保留本次弹窗内各方式的输入。示例从工作区根开始，将文章放在“文档”子目录中：跟随方式的资源与文章相邻，固定方式的资源位于工作区根下配置的位置。示例不代表目录存在，也不会创建文件。

| 选择 | 磁盘组织 | 适用条件 |
| --- | --- | --- |
| 固定目录 | 如 `public/images/`、`public/files/` | 适合公共静态资源目录，需匹配项目构建配置 |
| 跟随文档：带后缀目录 | `文章.md` → `文章.assets/` | 默认方式，适合普通 Markdown 工作区 |
| 跟随文档：同名目录 | `文章.md` → `文章/` | 需要文档同名资源目录的项目，须自行核对构建配置 |

### 路径与引用

图片和附件目录分别填写：固定方式相对项目根，跟随方式相对文档专属目录，后者可留空。文件名加入唯一前缀，图片名称会清理不适合路径的字符。格式及大小限制不变。

固定目录支持相对文档路径或站点根路径。站点根方式须指定其磁盘目录，例如 `public`，此时 `public/images/a.png` 写入正文为 `/images/a.png`。这里的 `/` 是站点地址，不是服务器文件系统根；无法配置多个互相冲突的站点根映射。资源存放方式旁的 ⓘ 可点击或键盘激活查看详细说明，Esc 关闭并返回触发按钮；常驻提示只保留路径基准和“仅影响后续上传”。点击“保存设置”统一执行路径、资源归属、引用冲突和版本校验；失败保留输入并提示原因，取消或关闭不保存。

### 保存与已有资源

设置保存在项目根 `.markdock.json`，包含格式版本、当前上传规则与兼容规则。分享工程时可一并保留该文件，不包含宿主机绝对路径或密钥。无此文件时使用内置的文章同级 `文章.assets/images/` 与 `文章.assets/file/`，不读取服务级资源设置；外部修改冲突或无效配置会提示，不静默覆盖。保存设置前须完成输入、上传及草稿保存。

切换只影响后续上传，不移动旧文件或改写旧文章。旧规则用于历史资源解析；不要手工删除兼容规则或改变已有站点根映射。固定资源不随文档进入垃圾箱；已识别的专属目录随文档在应用内移动、重命名或删除，按删除时的位置恢复。资源目录自身、包含固定资源或站点根的文件夹不能直接改名。外部工具的移动不由应用自动跟踪。

同名目录若含 Markdown 文档或存在资源归属冲突，不自动隐藏或搬迁；上传及有关文件操作会提示冲突。已有 `.assets/` 内的附件继续兼容。页面包 `文章/index.md`、批量迁移、任意命名表达式和框架自动检测暂不提供。不提供博客框架自动适配保证。

## 界面偏好

点击侧栏垃圾箱上方的“设置”，在“界面偏好”中选择简体中文或 English，以及浅色、深色或跟随系统。默认英文、跟随系统；已保存的语言选择保持不变。系统配色变化时自动更新外观。选择后立即生效。设置宽窗口使用左侧分类导航，窄窗口改为顶部导航。

界面偏好仅保存在当前浏览器，同源标签页同步，不影响其他设备；浏览器禁止存储时仅在当前页面会话生效并显示说明。文章内容、文件名、路径与 Markdown 不翻译，切换不重新打开文档、不生成编辑历史或触发保存。工作区主界面的菜单、提示和两种编辑模式使用所选语言与配色。

界面偏好还可分别控制字数统计、阅读时间和写作目标，默认全部显示；两种编辑模式均遵循设置。全部关闭后隐藏底部统计区；隐藏目标不会删除目标。源码模式按当前原文统计。图片与附件只在[工作区设置](#工作区资源设置)中调整。

开启“显示资源目录”后，文档树会展示已识别的资源目录；默认关闭。这个开关对当前浏览器的所有工作区生效，不写入项目配置。资源文件操作见[浏览资源](04-user-guide.md#浏览资源)。

系统启用“减少动态效果”时，界面过渡会相应关闭。

## 编辑历史与快捷键

“编辑”分类提供预设或整数自定义，点击“应用”才生效；“恢复默认”先恢复表单，仍需应用。设置同步到同源标签页，各页面分别管理自己的历史。

| 项目 | 范围 | 默认 |
| --- | --- | --- |
| 每篇最多保留批次 | 20–1,000 | 200 |
| 每篇历史预算 | 4–64 MiB | 16 MiB |
| 当前页面历史总预算 | 16–256 MiB | 64 MiB |

节省内存／均衡／更多历史预设分别为 100／8／32、200／16／64、500／32／128。单篇预算不能超过页面预算。预算覆盖撤销和重做，页面总额包含其他工作区仍驻留的文档。超限从最早撤销及最远重做记录淘汰，组字完成后再处理；调高预算不能恢复淘汰记录。单次编辑超过预算时保留正文和保存，但无法跨越该操作撤销，并显示非模态说明。

设置实时显示当前文档批次及历史占用、页面历史总量。占用按每条记录的修改前后文本 UTF-16 字符数乘以 2 估算，不是浏览器真实内存，不包含图片解码、编辑器节点及其他开销。刷新页面、重新读取磁盘版本或删除文档会释放对应历史；模式切换和自动保存不会清空历史。

“快捷键”按行内、段落和插入操作分组。点击组合键录入，Esc 仅取消录入，保留设置窗口和其他未应用修改；退出录入后再次按 Esc 关闭设置。每行解除链接图标用于取消绑定，重置图标用于单项恢复默认，悬停可查看名称；底部保留全部恢复默认和应用按钮。点击“应用”生效。Mac 和 Windows／Linux 的配置分别保留。当前默认组合如下：

| 操作 | 默认组合 |
| --- | --- |
| 粗体／斜体／链接 | 主键 + B／I／K |
| 行内代码／删除线 | 主键 + Shift + 反引号／X |
| 正文／H1–H6 | 扩展键 + 0／1–6 |
| 无序／有序／待办列表 | 扩展键 + U／O／L |
| 引用／代码块 | 扩展键 + 单引号／K |
| 插入表格／分隔线／图片／附件 | 扩展键 + T／H／I／A |

主键是 Mac Command 或其他平台 Ctrl；扩展键是 Mac Command + Control 或其他平台 Ctrl + Alt。录入按物理键码识别，拒绝重复、无修饰键及已登记的系统／浏览器保留组合。系统仍可能拦截自定义组合，网页不能保证收到所有按键。

格式快捷键只在可视化编辑区生效，遵守原文块、代码、表格及选区保护；菜单和工具栏显示当前绑定。源码保留自身的保存、查找、撤销和文本编辑操作。列表 Tab／Shift + Tab、表格导航不开放重绑定。组字和 AltGraph 输入不执行格式快捷键。
